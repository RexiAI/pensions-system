# AC-007-09 — Per-page SEO

## AC-007-18 — one canonical URL per route, in the link, og:url and the footer
Given any one of the 20 public routes
When the served document is read
Then the `<link rel="canonical">`, the `og:url` and the footer's citation line all equal
`canonicalUrl(path)` for that route's own path
And no route publishes another route's canonical

## AC-007-19 — every route advertises the reciprocal per-page alternate set
Given any one of the 20 public routes
When the route's metadata is resolved
Then its `alternates.languages` carries the same page in the five locales plus
`x-default` pointing at the Spanish page of that page kind
And every alternate href is an absolute canonical URL
And `alternateLinks` produces, per page kind, five locale hrefs of that page plus
`x-default` (never the home URL for a sub-page)

## AC-007-20 — the sitemap lists all 20 routes, robots still points at it
Given `sitemapEntries(SITE_URL)` and `robotsPolicy(SITE_URL)`
When both are resolved
Then the sitemap returns 20 entries — 4 pages × 5 locales — each with the per-page
alternates
And the sitemap advertises the same alternate set each page does (one source, two
surfaces that agree)
And `robots.txt` still points at `/sitemap.xml`

## AC-007-21 — the share card stays a single home-page asset
Given the opengraph image route for the home page
When the image is resolved
Then the home route generates the share card, and sub-pages do not generate their own
And `og:image:alt` on the home route is the home card's alt per locale (unchanged)
And the share card copy is unchanged
